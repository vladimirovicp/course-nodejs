# Модуль «Основы Node.js»

## Технические требования

- Используйте Node.js версии `24.x.x` (`24.10.0` или выше)

# Как проверять проект студента

1. Клонируйте репозиторий с проектом для проверки с помощью `git clone [HTTPS]` или скачайте его.
   (Где HTTPS — это GitHub URL проекта, который используется для клонирования. Чтобы его получить:
   a) перейдите в GitHub-репозиторий, который хотите клонировать
   b) нажмите _Code_ и скопируйте предложенный URL.)

2. Откройте следующие файлы:

- [Задание](https://github.com/AlreadyBored/nodejs-assignments/blob/main/assignments/nodejs-basics/assignment.md)
- [Подсчёт баллов](https://github.com/AlreadyBored/nodejs-assignments/blob/main/assignments/nodejs-basics/score.md)

3. Откройте проект в Visual Studio Code или любом другом редакторе кода.

4. Переключитесь с основной ветки на ветку с решением, если вы ещё этого не сделали.

5. Начните проверять подзадачи в соответствии с описанием задания.
   Для упрощения проверки ожидается, что у студентов будут `npm`-скрипты в `package.json`, позволяющие запускать каждую подзадачу.
   Если их нет, следуйте инструкции ниже:

Все задания находятся внутри папки `src`. Откройте терминал в папке **src** скачанного проекта.
Например, первая подзадача **create.js** находится в папке _fs_:

- Выполните `node fs/create.js` в терминале, открытом в папке _src_.
  Или перейдите в подпапку `fs/` задания и выполните `node create.js`.

## Шаги проверки подзадачи

- Согласно этой подзадаче после запуска функции в папке _files_ должен быть создан файл с именем `fresh.txt` (в начале такого файла не было, если он найден — удалите его).
- Откройте файл `fresh.txt`, и вы должны увидеть следующий текст, созданный функцией после её запуска:
  _I am fresh and young_.
- Попробуйте выполнить `node fs/create.js` ещё раз, и должна быть выброшена ошибка _FS operation failed_.
- Если всё вышеперечисленное работает как ожидается, добавьте _+6_ баллов к общей сумме, как указано в файле `Подсчёт баллов`.
- Если функция работает частично, вычтите баллы из максимума, допустимого для этой задачи.
  (Например, функция создаёт файл `fresh.txt`, но при повторном запуске не выбрасывает ошибку, то есть выполнена только половина задания. Добавьте за эту подзадачу только _+3_ балла).

- Если функция вообще не реализована, поставьте _0_.

- Продолжайте проверять все остальные подзадачи таким же образом. Добавляйте баллы за каждую к общей сумме.

5. После завершения проверки всех подзадач проверьте, есть ли штрафы:

- В `package.json` не должно быть внешних инструментов/библиотек в зависимостях.
  **-95% от общего балла за задание** Используются любые внешние инструменты/библиотеки
- Проверьте, что после дедлайна не было коммитов.
  **-30% от общего балла за задание** Коммиты после дедлайна (кроме коммитов, затрагивающих только `Readme.md`, `.gitignore` и т. п.).

6. Отправьте итоговый балл с деталями проверки в раздел cross-check этого задания в [приложении RS School](https://app.rs.school/) до дедлайна.
